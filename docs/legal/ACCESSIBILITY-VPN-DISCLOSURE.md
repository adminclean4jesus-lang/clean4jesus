# Divulgación de Accesibilidad y VPN

**Texto previo recomendado para Google Play y la app**

## Accesibilidad

### Acceso profundo, límites claros

Este permiso puede observar elementos visibles de otras aplicaciones porque esa es la capacidad que permite detectar una señal y mostrar la interrupción. Clean4Jesus no lo usa para robar información, registrar pulsaciones, leer contraseñas, operar bancos, enviar mensajes ni construir un historial de navegación. El contenido observado se procesa en el dispositivo.

Clean4Jesus usa el Servicio de Accesibilidad de Android para detectar cuándo una aplicación o contenido compatible requiere intervención y mostrar la pantalla privada del Refugio.

Puede observar texto visible necesario para evaluar reglas, pero ese texto se procesa en el dispositivo y no se envía a nuestros servidores. No usamos Accesibilidad para leer contraseñas, registrar teclas, enviar mensajes, realizar compras, controlar cuentas bancarias ni recopilar historial.

La persona debe activar el servicio voluntariamente desde Ajustes y puede desactivarlo en cualquier momento. Sin este permiso, la intervención sobre otras aplicaciones no funciona.

## VPN local

La VPN es local al dispositivo. No es un túnel para vender tu actividad ni para inspeccionar mensajes: enruta las consultas DNS necesarias para aplicar las reglas de protección. Puede haber datos técnicos mínimos asociados a un reporte voluntario de falso positivo, pero nunca se envían texto, URL, búsquedas, mensajes ni capturas.

Clean4Jesus crea una VPN local para aplicar filtrado DNS de protección. Android muestra el indicador de VPN mientras está activa.

La VPN no se usa para vender actividad, crear perfiles publicitarios ni inspeccionar mensajes. No garantiza bloquear todo contenido. Algunas redes, fabricantes o aplicaciones pueden comportarse de forma diferente.

## Consentimiento

Antes de abrir Ajustes del sistema, la app debe mostrar:

- qué permiso se solicita;
- para qué función concreta;
- qué datos no se recopilan;
- cómo desactivarlo;
- limitaciones principales;
- enlace a la Política de Privacidad.
